📖 Multi-Step Linear Inequalities: Comprehensive Theory & Video Hub

Linear inequalities describe a range of values rather than a single fixed solution. This hub combines foundational descriptive notes with curated video lessons from Khan Academy.

1. The Negative Reversal Rule

\[-ax > b \implies x < -\frac{b}{a}\]

When multiplying or dividing both sides of an inequality by a negative number, you must reverse the inequality symbol.

2. Multi-Step Procedure

1. Clear parentheses via the distributive property.

2. Combine like terms on each side independently.

3. Collect variable terms on one side and constants on the other.

4. Isolate the variable, flipping the sign if dividing by a negative coefficient.
